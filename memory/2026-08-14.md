## DF-022 — Collaborative multi-agent platform (`packages/multi-agent/`)

Built the multi-agent system reusing `@devforge/planner` (decomposeRequest/
buildPlanFor) and `@devforge/execution` (runVerification/CommandRunner). 300
tests across 17 suites. Stop condition met; task closed.

### Architecture
- 6 role agents: Planner, Coder, Reviewer, Tester, Repair, Documentation —
  each deterministic `createXAgent(backend?)` with injectable backend.
- `Coordinator` pipeline: begin → decompose/route → validateGraph →
  propagateConfirmations (REJECT → SKIPPED, MA_CONFIRMATION_REJECTED) →
  `scheduler.execute` → orderResults → MergeManager.merge → reportMerge →
  verifyLoop (≤ maxRepairRounds, synthetic `repair-${attempt}` tasks) →
  decideOutcome → buildReport.
- Concurrent execution via `ParallelRunner` (bounded, results always in input
  order). `Scheduler.buildSchedule` produces deterministic batches.

### Decisions worth remembering
- **Inject the clock into the Coordinator's scheduler** or determinism tests
  fail: coordinator passes `deps.now`/`deps.sleep` into its internal Scheduler
  constructor (they were DEFAULT before — messages stamped wall-clock).
- Scheduler `withTimeout` arms the timer only when `timeoutMs > 0` and defers
  arming one microtask so sync-resolving fake runners win ties vs instant clocks.
- Already-aborted cancel signal: loop must set `cancelled = true` at batch start
  when `isAborted(ctx)` (shared condition used to break) or outcome was CANCELLED
  only when a batch actually ran.
- Coordinator outcome gate is **verification.ok**, not per-task failures — a
  failing coder with `fixedVerifier(true)` still yields SUCCESS; test with
  `fixedVerifier(false)` to assert FAILED.
- Confirmation mode is overridden by an explicit `confirm` callback
  (`confirm ??= () => mode === 'AUTO_APPROVE'`); test mode REJECT by omitting
  the callback, not by passing `confirm`.
- `AgentPool.register` takes a `RoleAgent` (has `.role`) — registering a bare
  function silently keys it under `undefined` role.
- ConflictResolver default `fallback` is `undefined`; unset defers to
  `defaultStrategy` (code KEEP_FIRST, doc/test CONCATENATE). Explicit
  `{ fallback }` overrides.
- `toSummary`/verification.ts reads injected `now()` repeatedly; instant
  runners yield duration 0 — assert injected clock via message `at` stamps.
- Reviewer default backend reads artifacts from `ctx.artifacts`; seed
  `ctx.artifacts.put(...)` before expecting REVIEW_COMMENT messages.
