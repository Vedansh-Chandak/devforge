## DF-026A: provider-agnostic core for `@devforge/model-provider`

Built the normalized, production-grade core layer — additive only; `OpenAICompatibleProvider` + `FakeModelProvider` untouched. Report: `DF-026A-Stop-Condition-Report.md`.

### New modules (`packages/model-provider/src/`)
- `selection.ts` — `selectModel` / `selectModelName` / `resolveRoleModel`, `ModelSelection` (id + roles + priority), `RoleModelMap`. Rule: filter by role → sort by priority asc → stable declaration order. No "dedicated beats multi-role" heuristic (documented).
- `retry.ts` — `retry`, `shouldRetry`, `isRetryableCode`, `DEFAULT_RETRYABLE_CODES` (RATE_LIMITED/TIMEOUT/NETWORK_ERROR/PROVIDER_ERROR), `normalizePolicy`, `computeBackoff`, `defaultSleep`. Injectable `sleep` + `random` for determinism; `onRetry` callback. Contract: only retryable model errors with code in set; CANCELLED never; unknown thrown values never; exhaustion re-throws last error unchanged.
- `timeout.ts` — `withTimeout(work(signal), {timeoutMs, signal})`; deadline→TIMEOUT retryable, external abort→CANCELLED non-retryable; first-wins, loser suppressed; `timeoutMs <= 0` disables deadline.
- `redact.ts` — reuses `@devforge/errors` `redactSecretText` (single source of truth, avoids duplication) + `redactSecrets(value, secrets[])` (min secret length 6). Added `@devforge/errors` as the package's first runtime dep (`workspace:*`).
- `validate.ts` — `validateProviderConfig` (non-throwing), `assertValidProviderConfig` (throws INVALID_REQUEST), `isHttpUrl`.
- `structured.ts` — compact JSON-schema subset (`JsonObjectSchema`/`JsonPropertySchema`), `validateStructuredOutput`, `assertStructuredOutput` (PROVIDER_ERROR non-retryable), `parseJsonContent`/`stripCodeFence`.

### Types (`types.ts`, additive)
`ModelSelectionRole` ('reasoning'|'coding'|'fast'), `ModelCapabilities`, `ModelProviderInfo`; `ModelRequest` gains optional `timeoutMs`/`maxRetries`/`responseFormat` (`json_schema`|`json_object`)/`metadata`; `ModelResponse` gains optional `id`.
