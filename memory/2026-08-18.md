## vscode-extension tsconfig fixed (part of DF-026C follow-up)

Pre-existing failure from DF-026B resolved. `extensions/vscode/tsconfig.json`
was `module: "CommonJS"` + `moduleResolution: "Bundler"` + `ignoreDeprecations:
"6.0"` → TS5095 + TS5103 errors. Root cause: Bundler requires an ESM `module`,
but deps (@devforge/planner etc.) are ESM-only via `exports.import` so Node16
resolution would also fail for a CJS emitter. Fix: `moduleResolution: "Node10"`
(keeps CJS emit, permissive resolution), dropped the invalid `ignoreDeprecations`.

Root now fully green: check-types 26/26, build 26/26, test 46/46 (extension 311
tests), lint 3/3. Report (sections 16/18/20) updated accordingly.
