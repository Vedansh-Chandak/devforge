1. **`@devforge/execution` top-level index did not re-export DF-016B autonomous-coding symbols.** Added an "Autonomous Coding (DF-016B)" block re-exporting `DefaultPatchEngine`, `createPatchEngine`, `AutonomousCodingEngine`, `createCodingEngine` (values) and `CodePatch`, `CodingReport`, `PatchEngine`, `CodingEngineConfig`, etc. (types). 3. **Logger** only accepted a single message; CLI services passed `(message, meta)` at 7 call sites. Extended `Logger.write/debug/info/...` to accept optional `meta?`, and added the missing `ts` to `LogEntry` (ISO timestamp).
4. **`utils/output.ts`** `useColor` union type broke. Typed it explicitly (`Colorizer= (fn,s)=>s`).

6. **`routing/context.ts`** had `./services/*` imports — context.ts is in `routing/`, so they must be `../services/*`. Fixed 4.
7. **`config/validator.ts`** success path omitted required `errors` field → `{ ok: true, config, errors: [] }`.
8. **`commands/doctor.ts`** `HealthCheck` was local but `commands/index.ts` re-exports it → made `export`.
9. **`AskClassifiedResult` had no `confidence`** (bare `intent` classifier result) but `commands/explain.ts` reads `result.confidence`. Added `confidence: number` to the type in `packages/brain/src/types.ts`, populated `intent.confidence` at all 3 construction sites, and updated the one brain test fixture.
